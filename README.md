
# API de Biblioteca

## Objetivo

Este projeto tem como objetivo desenvolver uma API para
gerenciar livros de uma biblioteca.

A API permitirá cadastrar, consultar, atualizar e excluir
livros.

## Tecnologias

- Node.js
- Express
- Git e GitHub

## Instruções iniciais

1. Instale o Node.js.
2. Clone este repositório.
3. Instale as dependências do projeto com `npm install`.
4. Inicie a API após a implementação das funcionalidades.

## Funcionalidade inicial

A primeira funcionalidade a ser desenvolvida será o
cadastro de livros.
